Un poco de mi historia

La versión corta de por qué hago lo que hago.

Empecé copiando fragmentos de HTML y CSS porque era la forma más rápida de ver resultados reales. No pasó mucho tiempo antes de que un simple <div> se quedara corto y tuviera que aprender JavaScript, bases de datos y del lado del servidor.

Hoy trabajo con la misma curiosidad del primer día, pero con herramientas de adulto: Git para no perder nada, GitHub para documentar el proceso y GitHub Actions para automatizar el despliegue. Entiendo que el código se escribe para el equipo que lo leerá seis meses después, no solo para el navegador de hoy.

Cuando no estoy construyendo, estoy leyendo documentación, practicando lógica de programación o termino la GPU del portátil intentando entender por qué las pestañas tardan tanto.

“Un buen proyecto no es el que más código tiene, sino el que mejor explica por qué cada línea existe.”
