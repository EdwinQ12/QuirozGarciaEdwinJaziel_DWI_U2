# Descargas

Coloca aquí los archivos que se ofrecen en la sección **Descargas** del
portafolio y luego actualiza los enlaces en `index.html`
(busca `assets/descargas/`).

Archivos esperados:

| Archivo                         | Descripción                        | Formato |
| ------------------------------- | ---------------------------------- | ------- |
| `CV-Edwin-Quiroz.pdf`           | Currículum Vitae actualizado       | PDF     |
| `Portafolio-2025.pdf`           | Portafolio en versión imprimible   | PDF     |
| `Certificado-*.pdf`             | Certificados (opcional)            | PDF     |

> GitHub Pages sirve estos archivos tal cual. Mantén los nombres exactamente
> como están en el HTML o actualiza el atributo `href` de cada enlace `<a class="dl">`.
